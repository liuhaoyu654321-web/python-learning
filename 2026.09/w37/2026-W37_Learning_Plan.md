# 2026-W37 AI 学习计划

> 周期：2026-09-07 ～ 2026-09-13  
> 实际启动：2026-09-05（允许提前开始）  
> 本周定位：9 月“先学会看懂”阶段的第一个正式学习包  
> 核心原则：理解 > 数量；会做 > 看过；可以提前完成，但不为了赶进度牺牲理解。

## 1. 本周唯一核心目标

建立最基础的一条工程认知链：

**命令行 → JSON → HTTP / API**

到本周结束时，应该能够用自己的话解释：

- 如何通过命令行控制电脑做最基本的文件与程序操作；
- JSON 是什么、如何读懂简单 JSON；
- 一个程序如何向另一个服务发送请求并获得响应；
- 命令行、HTTP/API、JSON 三者如何在一次真实 API 调用中串起来。

---

## 2. 本周正式任务

### 任务 1：命令行最小基础

学习并实际使用 Windows PowerShell / Terminal 完成：

- 查看当前所在目录；
- 查看当前目录下有哪些文件和文件夹；
- 进入一个文件夹；
- 返回上一级目录；
- 在不同磁盘 / 路径之间移动；
- 创建一个简单学习目录或文件；
- 找到并运行一个简单 Python 文件；
- 初步看懂“一条命令 = 命令 + 参数 / 路径”的结构。

#### 完成标准

在少量提示或无提示情况下，可以完成：

**找到目标目录 → 进入目录 → 查看文件 → 找到 `.py` 文件 → 运行它**

并能解释自己刚才每一步在干什么。

---

### 任务 2：JSON 基础阅读

学习：

- `{}` 对象；
- `[]` 数组；
- key / value；
- 字符串；
- 数字；
- true / false；
- null；
- 简单嵌套结构。

#### 完成标准

看到一段陌生但简单的 JSON 时，可以：

- 说出它保存了哪些信息；
- 找到指定字段；
- 找到数组中的某一个元素；
- 修改一个值而不破坏基本格式；
- 用自己的话解释 JSON 为什么经常出现在 API 中。

---

### 任务 3：HTTP / API 最小基础

学习并理解：

- API 是什么；
- HTTP 是什么；
- Request（请求）；
- Response（响应）；
- URL；
- GET；
- Status Code；
- 为什么 API 经常返回 JSON。

实际使用 `curl` 调用至少一个公开 API。

#### 完成标准

能够用自己的话解释：

**我从电脑发出了什么 → 对方收到什么 → 对方返回什么 → JSON 在其中扮演什么角色。**

---

### 任务 4：把三件事真正串起来

亲自完成一次：

**命令行 → curl → HTTP 请求 → API → HTTP 响应 → JSON**

#### 完成标准

不照抄定义，可以画出或口头讲清整条数据流。

## 3. 本周辅助学习工具

### ChatGPT

主要负责：

- 系统教学；
- 概念解释；
- 小练习；
- 理解检查；
- 正式周测；
- Weekly Review。

### VS Code + Cline + DeepSeek

主要作为“代码现场学习助教”：

**先自己看 → 自己猜 → 圈出不懂的代码 → 让 DeepSeek 解释 / 提示 → 自己修改或运行 → 再检查理解**

学习任务中不要默认让 AI 直接把整个功能修改完成。

如果当天在 VS Code 中进行了较多代码阅读、修改或 Debug，可以让 DeepSeek 生成“当日代码学习总结”，之后上传给 ChatGPT，作为 Weekly Learning Log 的事实来源之一。

## 5. 本周学习记录规则

`2026-W37_Learning_Log.md`

记录重点：

- 今天实际学了什么；
- 用户真正能独立解释什么；
- 哪些仍依赖 AI；
- 报错 / Debug 经验；
- 值得周测复习的知识点。

## 6. W37 周末正式累计周测

本周结束时进行一次正式考试。

### 考试原则

- 用户独立作答；
- 考试时尽量不使用 ChatGPT / DeepSeek；
- 不只测试“记住定义”，还测试实际理解和操作；
- 后续周测采用累计制：主要考当周，同时抽取之前所有学过的核心内容。

### W37 首周主要题型

- 白话解释题；
- 命令行操作题；
- JSON 阅读 / 修改题；
- API 数据流解释题；
- 少量选择 / 判断题；
- 简单实际操作题。

### 考试后

ChatGPT：

1. 逐题评分；
2. 给出总分；
3. 区分“已掌握 / 基本掌握 / 仍不稳定”；
4. 纠错并解释；
5. 判断哪些内容需要进入下周复习；
6. 最终生成：

`2026-W37_Review.md`

本周不是以学习时长验收。

如果能够做到以下四件事，W37 就算成功：

1. 能在终端中自己完成基本目录操作，并运行一个简单 Python 文件；
2. 能读懂并修改简单 JSON；
3. 能用自己的话解释 API Request / Response；
4. 能讲清楚：

**命令行 → HTTP/API → JSON**

是如何在一次真实调用中连起来的。

如果提前达到标准，可以提前进入下一学习包，不需要等待自然周结束。
