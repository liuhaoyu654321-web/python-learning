先纠正一个关键点：**这里的 `todos` 不是数据库，而是内存里的列表。`todos.json` 才是保存数据的文件。**

例如：

```python
todos = [
    {"title": "学习 Python", "completed": False},
    {"title": "健身", "completed": True}
]
```

- `todos`：全部任务的列表。
- `todo`：其中一个任务的字典。
- `title`：任务名称。
- `completed`：是否完成，`True` 已完成，`False` 未完成。

**① `show_todos(todos)`：逐条显示任务**

```python
for index, todo in enumerate(todos, start=1):
```

`enumerate` 给列表中的任务配上编号，从 1 开始：

| 循环 | `index` 编号 | `todo` 当前任务 |
|---|---:|---|
| 第一轮 | 1 | `{"title": "学习 Python", "completed": False}` |
| 第二轮 | 2 | `{"title": "健身", "completed": True}` |

```python
titles = todo["title"]
```

从当前任务里取出 `"title"`，存进变量 `titles`。**字典里的字段叫 `title`；`titles` 只是临时变量名**，叫 `task_name` 也可以。

接下来根据 `completed`，打印：

```text
1 学习 Python - 未完成
2 健身 - 已完成
```

**② `add_todo(todos, title)`：添加任务**

接收：任务列表、一个新任务名称。

```python
todo = {
    "title": title,
    "completed": False
}
todos.append(todo)
```

先创建任务字典，默认未完成，再加入列表。

**`列表.append(要加入的东西)`**，所以这里是把后面的 `todo` 加进前面的 `todos`。这一步只改内存，`main.py` 随后调用 `save_todos(todos)` 才保存到文件。

**③ `complete_todo(todos, index)`：标记完成**

```python
index = index - 1
```

用户输入编号 1，对应列表位置 0，所以减 1。

然后循环寻找对应位置：

```python
if i == index:
    todo["completed"] = True
    break
```

找到后改成已完成，`break` 结束循环。这里 `enumerate(todos)` 没写 `start`，默认从 **0** 开始。

**④ `delete_todo(todos, index)`：删除任务**

```python
index = index - 1
todos.pop(index)
```

把用户编号转换为列表位置，再删除该位置的任务。

**`storage.py` 的两个疑问**

```python
except FileNotFoundError:
    return []
```

意思是：**如果找不到文件，返回空列表**。

`[]` 不是空字典，而是“目前没有任何任务”。第一次使用时还没有文件，也能正常开始添加。

```python
except json.JSONDecodeError:
    print("错误：todos.json 内容损坏，请检查文件")
    raise
```

意思是：文件存在，但内容无法解析为 JSON。打印提示后，`raise` **把刚才的错误继续抛出去**，当前程序会停止，方便检查；避免把损坏文件当作没有任务，之后保存时覆盖原数据。

**整个程序干什么**

```text
main.py 启动
→ storage.py 读取 todos.json，得到列表
→ 用户选菜单
→ todo.py 查看或修改列表
→ 修改后由 storage.py 保存回 todos.json
→ 继续显示菜单，直到退出
```

三个文件的分工：**`main` 管流程，`todo` 管任务操作，`storage` 管文件读写。**
